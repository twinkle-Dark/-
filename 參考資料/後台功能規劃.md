### Museums (博物館管理)

```sql
| 欄位名稱      | 資料類型    | 說明                    |
|-------------|------------|------------------------|
| museumId    | TEXT      | 博物館ID (主鍵)          |
| name        | TEXT      | 博物館名稱                |
| exhibitionHall | TEXT  | 展廳                    |
| section     | TEXT      | 廳別                    |
| description | TEXT      | 描述
| floorPlanUrl| TEXT      | 平面圖URL               |
| address     | TEXT      | 地址                    |
| contact     | TEXT      | 聯絡資訊                 |
| status      | TEXT      | 狀態                    |
| notes       | TEXT      | 備註                    |
                   |
```

```sql
| 欄位名稱      | 資料類型    | 說明                    |
|-------------|------------|------------------------|
| userId      | TEXT      | 用戶ID (主鍵)            |
```
